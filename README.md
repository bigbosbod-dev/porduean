# พอเดือน 💸

เว็บแอปวางแผนเงินรายเดือนสำหรับนักศึกษา บอกตัวเลขเดียวที่สำคัญที่สุด: **วันนี้ใช้เงินได้อีกกี่บาท ถึงจะอยู่รอดถึงวันเงินเข้ารอบหน้า**

👉 **ใช้งานได้ที่ <https://bigbosbod-dev.github.io/porduean/>**

## ทำอะไรได้

- **วันนี้ใช้ได้อีกเท่าไหร่**: คำนวณจากเงินที่เหลือหารด้วยจำนวนวันจนถึงวันเงินเข้า ถ้าวันนี้ใช้น้อย วันต่อ ๆ ไปจะได้เพิ่ม ถ้าใช้เกิน วันต่อ ๆ ไปจะได้น้อยลง
- **ตั้งรายรับ วันเงินเข้า เงินเก็บ และค่าใช้จ่ายประจำ** (ค่าหอ ค่าโทรศัพท์): หักออกจากงบให้ก่อน
- **จดรายจ่ายเร็ว ๆ** แยกหมวด อาหาร / เดินทาง / ของใช้ / บันเทิง / การเรียน / อื่น ๆ และจดรายรับเพิ่มได้ (เช่น ค่าจ้างพาร์ทไทม์)
- ⚠️ **เตือนเมื่อใกล้ใช้เกินงบของวัน**: ระหว่างพิมพ์จำนวนเงินจะบอกล่วงหน้าว่าจดแล้ววันนี้จะเหลือเท่าไหร่ เมื่อใช้ถึงเกณฑ์ (70/80/90% ของงบวันนี้ ตั้งได้หรือปิดได้ในแท็บตั้งค่า) การ์ดหน้าแรกจะเปลี่ยนเป็นสีส้มและเด้งเตือน ถ้าเกินงบจะบอกว่าพรุ่งนี้เหลือใช้ได้เท่าไหร่
- **ประวัติแต่ละรอบ**: ย้อนดูรอบก่อน ๆ มี**กราฟรายจ่ายรายวัน**เทียบกับเส้นงบต่อวัน (วันที่เกินเป็นสีส้ม แตะที่แท่งเพื่อดูยอดของวันนั้น) และสรุปว่าใช้ไปกับหมวดไหนเท่าไหร่
- 🌙 โหมดมืด · 📱 ติดตั้งเป็นแอปบนมือถือ · ✈️ ใช้งานออฟไลน์ได้ · 💾 สำรอง/นำเข้าข้อมูลเป็นไฟล์ `.json`

### วิธีคิด

```
งบใช้จ่าย       = เงินต่อเดือน + รายรับเพิ่ม − ค่าใช้จ่ายประจำ − เงินเก็บ
งบวันนี้         = (งบใช้จ่าย − ที่ใช้ไปในวันอื่นของรอบ) ÷ วันที่เหลือ (รวมวันนี้)
วันนี้ใช้ได้อีก   = งบวันนี้ − ที่ใช้ไปวันนี้
```

"รอบ" นับตั้งแต่วันเงินเข้า ถึงวันก่อนเงินเข้าครั้งถัดไป ถ้าตั้งเงินเข้าวันที่ 31 เดือนที่มีไม่ถึง 31 วันจะใช้วันสุดท้ายของเดือนแทน

> ข้อมูลเก็บอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น (`localStorage` คีย์ขึ้นต้นด้วย `pd_` เพื่อไม่ชนกับ StudyFlow ที่อยู่โดเมนเดียวกัน)

## ติดตั้งบนมือถือ

- **iPhone / iPad:** เปิดลิงก์ใน Safari แล้วแตะปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android:** เปิดลิงก์ใน Chrome แล้วแตะเมนู ⋮ → **ติดตั้งแอป** หรือกดปุ่ม "ติดตั้งแอป" ในแท็บตั้งค่า

## รันในเครื่อง

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## โครงสร้างไฟล์

```
index.html            หน้าเว็บ
css/style.css         สไตล์เพิ่มเติม
js/app.js             โค้ดการทำงานทั้งหมด
sw.js                 service worker (ใช้ออฟไลน์ได้)
manifest.webmanifest  ข้อมูลสำหรับติดตั้งเป็นแอป
icons/                ไอคอนแอป
```

เมื่อแก้ไฟล์ของแอป ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `porduean-v2`) เพื่อให้เครื่องที่ติดตั้งแอปไว้ได้เวอร์ชันใหม่
